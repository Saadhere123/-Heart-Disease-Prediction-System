                                                      ❤️ Heart Disease Prediction System

A Machine Learning project that predicts whether a person is at risk of heart disease based on medical and health data. This project uses classification algorithms and includes data cleaning, Exploratory Data Analysis (EDA), model training, evaluation, and deployment with Streamlit.

---

📌 Project Objective

The main objective of this project is to build a predictive model that can identify heart disease risk using patient health information such as:

- Age
- Gender
- Chest Pain Type
- Blood Pressure
- Cholesterol
- Maximum Heart Rate
- Exercise Angina
- ECG Results
- Other medical indicators

---

📂 Dataset Used

**Heart Disease UCI Dataset**  
Available on Kaggle / UCI Repository

---

📊 Project Workflow

1️⃣ Data Cleaning

- Removed unnecessary columns
- Handled missing values
- Converted target labels into binary classification

2️⃣ Exploratory Data Analysis (EDA)

- Disease distribution
- Age trends
- Correlation heatmap
- Cholesterol analysis
- Gender-based risk analysis

3️⃣ Model Training

Used classification models:

- Logistic Regression
- Decision Tree Classifier

4️⃣ Model Evaluation

Measured performance using:

- Accuracy Score
- Confusion Matrix
- ROC Curve
- ROC-AUC Score

5️⃣ Feature Importance

Identified top factors affecting heart disease prediction.
